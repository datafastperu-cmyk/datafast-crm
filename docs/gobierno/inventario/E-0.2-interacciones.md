# E-0.2 — Auditoría de interacciones

Generado por `auditoria-interacciones.ts` el 2026-08-11.
Es la fotografía de cómo funciona Datafast **hoy**, no una propuesta de diseño.
No se edita a mano: se vuelve a correr con `npm run interacciones`.

> **Límites declarados.** Se miden llamadas por servicio inyectado en el constructor
> (`this.x.y()`), escrituras en SQL crudo y por repositorio TypeORM, y eventos con nombre
> literal. Un `moduleRef.get()`, una llamada dinámica o un nombre de evento construido en
> ejecución no se ven. Las cifras son un **suelo**.

|---|---:|---|

| colección | 86 | Lectura de varios. |

| boolean | 30 | Éxito/fallo sin causa. Un false no dice si reintentar. |
| string (id o texto) | 29 | Identificador o mensaje. |
